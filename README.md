# Zombietown

Jeu de zombies 2D en pixel art, à défilement horizontal, pour téléphone en mode paysage.

- Joystick à gauche : avancer, monter aux échelles jaunes
- Bouton à droite : tirer, ou frapper à la batte sans munitions
- Trois niveaux : Bronx (coucher du soleil), Manhattan (nuit), Zone 51 (plein jour). Atteindre le bunker valide le niveau.

Ouvrir `index.html` dans un navigateur. Au clavier : flèches et espace.
